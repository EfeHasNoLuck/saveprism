## Yapılacaklar
Put the logic in a plain Rust module (e.g. `src/session.rs`) with no Tauri types so it is unit-testable; `lib.rs` only wraps it in
`#[tauri::command]` functions and keeps one `Mutex<Option<Session>>` in Tauri managed state.

1. `open_file(path, password: Option<String>) -> OpenInfo`: detect + decode with the registered codecs, run the round-trip guard.
   `OpenInfo`: file name, full path, format/codec id, byte size, guard result (`exact` | `semantic` | `failed`), `editable` (false when
   guard failed), optional warning text, root node info (path + child count). An encrypted ES3 without a password (or a wrong one)
   returns a distinct error code so the UI can ask for a password. The password is never logged or stored on disk.
2. `get_children(path, offset, limit) -> Page<NodeRow>`: `NodeRow` = path (string form used by the core path module), key/index,
   kind (object | array | string | int | float | bool | null | bytes/other), short value preview (≤120 chars), child count,
   editable flag. `limit` capped at 500.
3. `search(query, offset, limit) -> Page<NodeRow>`: case-insensitive substring match on the path text and on the scalar value text.
   Empty query → empty page. Cap total hits at 10 000 (report `truncated: true`). Sequential is fine.
4. `edit_value(path, text) -> NodeRow`: parse `text` by the node's current type: int (respect the original width/sign range where the
   doc keeps it, else i64), float, bool (`true`/`false`), string. Wrong type or out of range → error with a reason and a fix hint.
   Read-only document → error. Keeps a pending-changes list in the session.
5. `pending_changes() -> Vec<{path, old, new}>` and `discard_changes()`.
6. `save(target: String) -> SaveResult`: encode with the recipe and write with the core safe-write path (backup in the app data dir via
   the core `default_backup_root`, temp file → atomic replace), then reopen the written file and check every edited value.
   `target == original path` = overwrite (backup always taken); any other path = "save as" (no backup needed, but never overwrite an
   existing different file silently: return an error code unless `overwrite: true` is passed). `SaveResult`: written path, backup
   path (if any), `verified: bool`. Verification failure → restore from backup (overwrite case) and return an error.
7. Errors cross IPC as `{ code: "SP-…", message, hint }` (serde). No panics: no `unwrap`/`expect` (workspace lints deny them).
8. `apps/desktop/src/api/commands.ts`: hand-written TS types matching the Rust structs + typed `invoke` wrappers for every command
   (`@tauri-apps/api/core`). No other frontend changes.

## Testler (Rust, in the desktop crate)
Using `fixtures/synthetic/**` copied into a `tempfile` dir: open JSON/RPG Maker/ES3 → guard `exact` · children paging (offset/limit)
· search finds a key by path and a value by text · edit int/bool/string ok, bad int → error, out-of-range → error · save-as to a new
path → reopen shows the new value, original unchanged · overwrite → backup file exists and new value present · save-as onto an
existing file without `overwrite` → error · encrypted ES3 without password → the password error code; with `synthetic-test-key`
→ opens.
