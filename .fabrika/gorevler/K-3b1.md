## User rules (2026-10-22, verbatim intent)
- No AI-slop labels: no "Safe to edit", no green status dots, no onboarding step strips, no "Where is my save?" cards (only a small
  "FAQ: where are save files?" link at the bottom of the start screen that expands a short list: RPG Maker `<game>/save/` or `www/save/`,
  Unity `%USERPROFILE%\AppData\LocalLow\<Company>\<Game>`, Unreal `%LOCALAPPDATA%\<Game>\Saved\SaveGames`).
- Recent files hidden unless the user turns them on in Settings ("Show recent files", default off; last 5, stored locally).
- Technical words are fine ("Open JSON", "backup"); explain with an (i) tooltip, not extra lines.
- Calm layout, no busy document look; dark-mode text must be readable everywhere (≥ 4.5:1).
- Settings = centered modal, dimmed + blurred backdrop, closes on X, Esc, outside click. Never a side sheet.

## Yapılacaklar
1. **Header:** logo mark (two interlocking squares forming an 8-point star, woven, blues #4A7FD6 / #8FC0F7; inline SVG) + "SavePrism";
   when a file is open: file name + engine badge. Right: "Open file" (primary), language dropdown (English, Türkçe), light/dark toggle,
   notifications bell (count badge; popover with this session's events: opened, saved, backup path, errors), settings gear.
2. **Start screen:** centered drop zone "Drop a save file here" + "Open file" + one muted line "Files stay on this computer. A backup is
   made before every save." + optional recent files + FAQ link. Drag-and-drop via `getCurrentWebview().onDragDropEvent` (path → openFile).
   "Open file" uses the dialog plugin `open()`.
3. **Open flow:** `openFile(path)`; password-needed error → small modal asking for the password, retry with it (never stored);
   guard failed → yellow banner "This file can't be written safely yet. You can look, but not save." and the editor in read-only mode;
   other errors → message + hint in a toast and in the bell.
4. **Bottom bar** (sticky, file open): "N changes" (popover listing `pendingChanges()`: path, old → new), "Undo all" (`discardChanges`),
   "Open JSON" (modal: read-only pretty JSON of the document from a new `export_json` command, with search + Copy; editing JSON is later),
   primary split button "Save as…" (dialog `save()` → `save(target)`) with menu item "Overwrite original (backup is made first)"
   (`save(originalPath, overwrite)`); default action follows Settings. Save is disabled while EditorView reports `onInvalidChanged(true)`
   or the file is read-only.
5. **Saved:** toast "Saved · backup created · verified" with the written path and "Show in folder" (`revealItemInDir` from
   `@tauri-apps/plugin-opener`); bell gets the event. Verification failure → error toast with hint.
6. **Settings modal:** Appearance (Theme: System/Light/Dark; Background pattern on/off; Pattern strength slider) · Language · Saving
   (Default action: Save as new file / Overwrite original) · Recent files (Show recent files) · Notifications (Show notifications).
   Only settings that work. Persist in localStorage (wrapped in try/catch).
7. **Colors (OKLCH tokens in `index.css`):** neutrals hue 255 chroma 0.01–0.02. Dark: page L .15, surface .19, raised .23, border .30,
   text .96, muted .74. Light: page .98, surface 1.0, raised .96, border .88, text .20, muted .45. Brand oklch(.62 .16 255) only for primary
   actions, focus, selection; success/warning/error at similar L/C.
8. **Background pattern:** continuous lattice of the two-square star (lines connect, no gaps), thin stroke, ~3% opacity dark, ~2% light,
   CSS background from an inline SVG; toggle + strength from Settings.
9. **Window:** `tauri.conf.json` default 1280×800, min 1024×700, title "SavePrism". Capability `dialog:default` (+ opener reveal).
10. `export_json`: pretty JSON string of the open document (reuse the JSON codec), ≤ 50 MB else error.
