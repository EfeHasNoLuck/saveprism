## Yapılacaklar
1. **pnpm workspace:** `pnpm-workspace.yaml` → `packages: ["apps/*"]`. Kök `package.json`: `name: "saveprism"`, `private: true`,
   `packageManager: "pnpm@11.19.0"`, `engines.node: ">=22"`. Script'ler yalnız masaüstü paketine yönlendirir:
   `dev` (`pnpm --filter @saveprism/desktop tauri dev`), `build` (`… tauri build`), `tauri` (`pnpm --filter @saveprism/desktop tauri`),
   `typecheck` (`pnpm --filter @saveprism/desktop typecheck`). `lint` ve `test` EKLEME (M0-8'in işi).
2. **Masaüstü paketi:** `apps/desktop/package.json` → `name: "@saveprism/desktop"`, `version: "0.0.1"`; script `typecheck: "tsc --noEmit"`
   ekle; mevcut script'leri koru. devDependencies'e `"tailwindcss": "^4.1.0"` ve `"@tailwindcss/vite": "^4.1.0"` ekle (onaylı). Başka paket yok.
3. **Vite + TS:** `vite.config.ts` → Tailwind eklentisi (`@tailwindcss/vite`) + `resolve.alias: { "@": "/src" }` (Node API'si kullanma;
   `@types/node` onaylı değil). Şablonun Tauri sunucu ayarlarını (port 1420, strictPort, `src-tauri` izleme dışı, TAURI_DEV_HOST) koru.
   `tsconfig.json` → `paths: { "@/*": ["./src/*"] }` (`baseUrl` yok; TypeScript 6'da kullanımdan kalktı), `strict` açık kalsın.
4. **HTML + CSS:** `index.html` → `<title>SavePrism</title>`, `lang="en"`, `<meta name="color-scheme" content="light dark">`, silinen
   favicon bağlantısını kaldır. `src/index.css` → `@import "tailwindcss";` + `:root { color-scheme: light dark; }` (token'lar M0-6'da).
5. **D2 sözleşmesi (taslaklar, M0-6 ve M0-7 dolduracak; dışa açılan adlar ve imzalar değişmez):**
   - `src/theme/index.tsx`: `export type ThemePreference = "light" | "dark" | "system"` · `export function applyStoredTheme(): void`
     (taslak: hiçbir şey yapmaz) · `export function ThemeProvider({ children }: { children: React.ReactNode })` (taslak: children döner) ·
     `export function ThemeToggle()` (taslak: `null` döner). Dosya başına sözleşmeyi anlatan kısa JSDoc.
   - `src/i18n/index.tsx`: `export const SUPPORTED_LANGUAGES = ["en", "tr"] as const` · `export type Language` ·
     `export function initI18n(): void` (taslak: hiçbir şey yapmaz) · `export function LanguageSwitcher()` (taslak: `null` döner).
   - `src/main.tsx`: `import "./index.css"` → `applyStoredTheme()` → `initI18n()` → `createRoot(...).render(<StrictMode><ThemeProvider><App/></ThemeProvider></StrictMode>)`.
     `#root` yoksa sessizce çökme; anlaşılır bir `Error` fırlat.
6. **App kabuğu (`src/App.tsx`):** tam yükseklikte yerleşim: üst çubuk (sol: "SavePrism" yazısı; sağ: `<LanguageSwitcher/>` ve
   `<ThemeToggle/>`), ortada boş durum ("Drop a save file here" + alt satır "Everything stays on your computer."), alt çubukta
   `core v<sürüm>` (Rust'tan `invoke("core_version")` ile; hata olursa "core unavailable"). Sade Tailwind sınıfları; renkler M0-6'da token'a geçer.
   Metinler bu dalgada düz İngilizce kalabilir; M0-7 hepsini i18n anahtarına taşıyacak.
7. **Cargo workspace (kök `Cargo.toml`):** `[workspace] resolver = "3"`, `members = ["apps/desktop/src-tauri", "crates/*"]`.
   `[workspace.package]`: `version = "0.0.1"`, `edition = "2024"`, `license = "MIT"`, `rust-version = "1.85"`, `repository` boş bırak.
   `[workspace.lints.rust]`: `unsafe_code = "deny"`. `[workspace.lints.clippy]`: `unwrap_used`, `expect_used`, `panic`, `indexing_slicing`,
   `todo`, `unimplemented`, `dbg_macro` = `"deny"`. `[profile.release]` bloğunu şablon crate'inden köke taşı (üye crate'teki profil yok sayılır).
8. **Araç zinciri:** `rust-toolchain.toml` → `channel = "stable"`, `components = ["rustfmt", "clippy"]`, `profile = "minimal"`.
   `clippy.toml` → `allow-unwrap-in-tests`, `allow-expect-in-tests`, `allow-panic-in-tests`, `allow-indexing-slicing-in-tests` = `true`.
9. **Tauri crate:** `src-tauri/Cargo.toml` → `name = "saveprism-desktop"`, `description = "SavePrism desktop app"`, `authors` satırını sil,
   version/edition/license `workspace = true`, `[lib] name = "saveprism_desktop_lib"` (crate-type aynı), `[lints] workspace = true`,
   bağımlılık `saveprism-core = { path = "../../../crates/saveprism-core" }`. `main.rs` yeni lib adını çağırır.
   `lib.rs`: `greet` komutunu kaldır; `#[tauri::command] fn core_version() -> &'static str` (`saveprism_core::VERSION` döner) ekle;
   `run()` içinde `.expect` yok: hata olursa `eprintln!("SP-APP-001: failed to start SavePrism: {err}")` ve `std::process::exit(1)`.
10. **tauri.conf.json:** `productName: "SavePrism"`, `version: "0.0.1"`, `identifier: "app.saveprism.desktop"` (değiştirme: yedek klasörünü bu belirler),
    pencere `title: "SavePrism"`, 1200×800, en küçük 900×600, ortada. `security.csp`: `default-src 'self'; img-src 'self' data: asset:;
    style-src 'self' 'unsafe-inline'; connect-src ipc: http://ipc.localhost` (dev modunda Vite HMR bozulursa CEO düzeltme turunda bildirir).
    `capabilities/default.json`: pencere `main`, izinler `core:default` + `opener:default`, açıklama SavePrism'e göre.
11. **Çekirdek crate:** `crates/saveprism-core/Cargo.toml` (`name = "saveprism-core"`, workspace alanları, `[lints] workspace = true`, bağımlılık yok).
    `src/lib.rs`: crate düzeyi doc yorumu (ne olduğu, M1'de SaveDoc/Codec geleceği) + `pub const VERSION: &str = env!("CARGO_PKG_VERSION");`
    + `#[cfg(test)]` içinde `VERSION` boş değil testi.
