## Yapılacaklar
1. **Script'ler:** masaüstü `lint: "eslint ."`, `test: "vitest run --passWithNoTests"`. Kök: `lint` ve `test` → `pnpm --filter @saveprism/desktop <ad>`.
   `kontrol.sh web` kök script'lerden `typecheck`, `lint`, `test`'i koşar.
2. **`eslint.config.js`** (flat config): `@eslint/js` recommended + `typescript-eslint` recommended (tip bilgisi gerektirmeyen) +
   `react-hooks` recommended + `react-refresh` (`only-export-components`, uyarı). `globals.browser`. Yok say: `dist`, `src-tauri`,
   `node_modules`. `react-refresh` kuralını kapat: `src/components/ui/**` (shadcn üretimi) ve sözleşme dosyaları `src/theme/index.tsx`,
   `src/i18n/index.tsx`. Hedef: 0 hata.
3. **`vitest.config.ts`:** `environment: "node"`, `include: ["src/**/*.test.ts"]`, `@` takma adı `src`'ye.
4. **`ci.yml`:** ad `ci`; tetik `push` (main), `pull_request`, `workflow_dispatch`; `permissions: contents: read`; `concurrency` (aynı ref'te eskiyi iptal).
   - **rust** işi, matris `ubuntu-24.04`, `windows-latest`, `macos-latest` (fail-fast kapalı), zaman aşımı 40 dk:
     checkout → (yalnız Linux) Tauri sistem paketleri: `libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev libxdo-dev libssl-dev patchelf build-essential` →
     `dtolnay/rust-toolchain@stable` (components: rustfmt, clippy) → `Swatinem/rust-cache@v2` →
     Tauri derleme anında `apps/desktop/dist` klasörünü isteyebilir: önceden boş bir `apps/desktop/dist/index.html` oluştur (yorumla açıkla) →
     `cargo fmt --all -- --check` → `cargo clippy --workspace --all-targets -- -D warnings` → `cargo test --workspace`.
   - **web** işi, `ubuntu-24.04`, zaman aşımı 15 dk: checkout → `pnpm/action-setup@v4` (sürüm `packageManager`'dan) → `actions/setup-node@v4`
     (node 22, pnpm cache) → `pnpm install --frozen-lockfile` → `pnpm typecheck` → `pnpm lint` → `pnpm test` → `pnpm --filter @saveprism/desktop build`.
5. **`dependabot.yml`:** `cargo` (/), `npm` (/), `github-actions` (/), haftalık; minor+patch güncellemeleri tek grupta.
