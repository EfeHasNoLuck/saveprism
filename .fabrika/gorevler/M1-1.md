## Modüller (`crates/saveprism-core/src/`)
`lib.rs`: crate doc yorumu, `pub mod` listesi, ana tiplerin yeniden dışa açılması (`pub use`), mevcut `VERSION` sabiti ve testi korunur.

1. **`error.rs`**
   - `pub type Result<T, E = Error> = std::result::Result<T, E>;`
   - `pub struct ErrorCode(&'static str)` (`Copy`, `Eq`, `Hash`, `Debug`) · `pub const fn new(code: &'static str)` · `as_str()` ·
     `i18n_key() -> String` (`"SP-CORE-001"` → `"error.sp-core-001"`) · `Display` = kodun kendisi.
   - `#[derive(Debug, thiserror::Error)] pub struct Error`: `code`, `message: String` (teknik metin), `offset: Option<u64>`,
     `context: Vec<String>`, `#[source] source: Option<Box<dyn std::error::Error + Send + Sync>>`.
     Yapıcılar ve erişim: `new(code, message)`, `with_offset(u64)`, `with_source(e)`, `context(self, impl Into<String>) -> Self`
     (zincire ekler), `code()`, `message()`, `offset()`, `context_chain() -> &[String]`, `report() -> String` (çok satırlı:
     `SP-…: message (offset 0x1A0)` + her bağlam satırı `  while …`). `Display` = `"{code}: {message}"`.
   - `pub trait ResultExt<T> { fn context(self, f: impl FnOnce() -> String) -> Result<T>; }` (`Result<T>` için uygula).
   - `pub mod codes` — çekirdek kodları (her birine bir satır doc yorumu):
     `CORE_NOT_IMPLEMENTED` SP-CORE-001 · `CORE_UNKNOWN_STEP` 002 · `CORE_INVALID_RECIPE` 003 · `CORE_RECIPE_FORMAT` 004 (TOML) ·
     `CORE_INVALID_PARAM` 005 · `CORE_LIMIT_INPUT` 006 · `CORE_LIMIT_DECODED` 007 (boyut / oran = bomba) · `CORE_LIMIT_DEPTH` 008 ·
     `CORE_LIMIT_NODES` 009 · `CORE_LIMIT_LAYERS` 010 · `CORE_INVALID_PATH` 011 · `CORE_EDIT_FAILED` 012 · `CORE_READ_ONLY` 013 ·
     `DET_NO_MATCH` SP-DET-001 · `DET_BUDGET` SP-DET-002 ·
     `IO_BACKUP` SP-IO-001 · `IO_TEMP_WRITE` 002 · `IO_REPLACE` 003 (dosya kullanımda / izin) · `IO_VERIFY_RESTORED` 004 ·
     `IO_RESTORE_FAILED` 005 · `IO_NO_BACKUP_ROOT` 006 · `IO_READ` 007.
     Codec crate'leri kendi kodlarını kendi modüllerinde `ErrorCode::new("SP-JSON-001")` ile tanımlar.

2. **`doc.rs`**
   - `pub struct NodeId(u32)` (`Copy`, `Eq`, `Ord`, `Hash`, `Debug`) · `index() -> usize`.
   - `pub enum IntWidth { I8, I16, I32, I64, U8, U16, U32, U64, Unbounded }` (`Unbounded` = metin formatları) ·
     `pub enum FloatWidth { F32, F64 }`.
   - `pub struct TypeHint(Box<str>)` · `new(impl Into<Box<str>>)` · `as_str()`. Biçim `"<alan>:<ad>"`, ör. `"JSON:float"`.
   - `pub struct NodeFlags(u8)` · sabitler `READ_ONLY`, `SYNTHETIC` · `empty()`, `contains`, `insert`, `remove`. (bitflags crate'i yok.)
   - `pub struct ByteSpan { pub start: u64, pub end: u64 }`.
   - `pub enum Value` ve `pub struct Node` — MIMARI §3.2'deki gibi (alanlar `pub`). `Node::new(value)` kolaylığı.
   - `pub struct SaveDoc { nodes: Vec<Node>, root: NodeId }` (alanlar özel). Yöntemler:
     `new()` (kök = `Null`) · `push(Node) -> NodeId` (önce çocuklar, sonra kap: düzenleyici `&mut Node` dışarı verilmez) ·
     `set_root(NodeId)` · `root()` · `len()` · `get(id) -> Option<&Node>` · `children(id) -> Vec<NodeId>` ·
     `resolve(&Path) -> Option<NodeId>` · `set_value(id, Value) -> Result<()>` (`lexeme`'i siler; `READ_ONLY` ise
     `CORE_READ_ONLY`) · `set_flags(id, NodeFlags) -> Result<()>` · `tree_eq(&self, other) -> bool`: yapı, değer, genişlik ve
     `type_hint` karşılaştırılır; `lexeme`, `span`, `flags`, `NodeId` numaraları yok sayılır; float `to_bits` ile; **özyinelemesiz**
     (açık yığın), derin ağaçta yığın taşmaz.
   - `Ref` döngü kurabilir: `tree_eq` `Ref`'in hedefine inmez, iki `Ref`'i eşit sayar ve bunu yorumla belgeler (M2'de JsonEx ile netleşir).

3. **`path.rs`** — `pub struct Path(Vec<String>)` JSON Pointer (RFC 6901): `parse(&str) -> Result<Path>` (`""` = kök, `/a/~1b/~0c`),
   `Display`, `push`, `segments()`. Çözüm kabın türüne göre: `Object` → anahtar (tekrar ediyorsa ilk eşleşme), `Array` → indeks,
   `Map` → giriş indeksi ve **değer** düğümü. Geçersiz → `CORE_INVALID_PATH`.

4. **`edit.rs`**
   - `pub enum OwnedValue { Null, Bool(bool), Int(i128), Float(f64), Str(String), Bytes(Vec<u8>), Array(Vec<OwnedValue>),
     Object(Vec<(String, OwnedValue)>) }` (AI yamaları ve testler için sahipli ağaç).
   - `pub enum Position { Index(usize), Key(String), End }`
   - `pub enum Edit { Set { path: Path, value: OwnedValue }, Insert { parent: Path, at: Position, value: OwnedValue },
     Remove { path: Path }, RenameKey { path: Path, new_key: String } }`
   - `pub fn apply_edits(doc: &mut SaveDoc, edits: &[Edit]) -> Result<()>`: **atomik** (klonda uygula, hepsi geçerse değiştir; hata
     olursa belge aynen kalır). `Set` mevcut genişliği korur (`Int` için düğümün `IntWidth`'i; aralık dışıysa `CORE_EDIT_FAILED`).
     `Map` üzerinde `Insert`/`RenameKey` M1'de `CORE_EDIT_FAILED` ("not supported yet"). `READ_ONLY` → `CORE_READ_ONLY`.

5. **`params.rs`**
   - `pub enum ParamValue { Bool(bool), Int(i64), Float(f64), Str(String), Bytes(Vec<u8>), List(Vec<ParamValue>), Table(Params) }`
   - `pub struct Params(BTreeMap<String, ParamValue>)` (anahtar sırası önemsiz, çıktı kararlı) · `new`, `set(key, impl Into<ParamValue>)`,
     `get`, `contains`, `len`, `is_empty`, `iter` · tipli okuma: `bool(key)`, `int(key)`, `float(key)`, `str(key)`, `bytes(key)` →
     `Result<…>` (yok ya da yanlış tip → `CORE_INVALID_PARAM`, mesajda anahtar adı) ve `opt_bool` … `opt_bytes` → `Result<Option<…>>`.
     `From` uygulamaları: `bool`, `i64`, `u32`, `f64`, `String`, `&str`, `Vec<u8>`.
   - Elle `Serialize` / `Deserialize` (toml tipleri dış API'ye sızmaz): `Bytes` → `"base64:<standart, dolgulu>"`; `"base64:"` ya da
     `"str:"` ile başlayan `Str` → başına `"str:"` eklenir; okurken `"base64:"` → `Bytes`, `"str:"` → bir kez soyulur. `u64` > `i64::MAX`
     → hata. Ayrılmış anahtar: `kind` (Params'ta olamaz).

6. **`recipe.rs`**
   - `pub struct Step { pub kind: String, pub params: Params }` · `pub struct Recipe { pub version: u32, pub steps: Vec<Step> }`
     (`version = 1`).
   - TOML biçimi (MIMARI §3.1): en üstte `version = 1`, sonra her adım `[[layer]]` tablosu: `kind = "…"` + parametreler düz alan olarak.
     Gerekirse ara bir serde yapısı kullan (`#[serde(flatten)]` sorun çıkarırsa elle `Deserialize`).
   - `to_toml() -> Result<String>` · `from_toml(&str) -> Result<Recipe>` (`CORE_RECIPE_FORMAT`) · `kinds() -> Vec<&str>` ·
     `validate(&self, reg: &Registry, limits: &Limits) -> Result<()>`: boş değil; sonuncusu codec, öncekiler katman; adım sayısı ≤
     `max_layers + 1`; bilinmeyen tür → `CORE_UNKNOWN_STEP`; diğerleri `CORE_INVALID_RECIPE`.

7. **`limits.rs`** — `pub struct Limits` (`pub` alanlar, `Clone`, `Debug`, `PartialEq`) ve `Default`:
   `max_input_bytes` 256 MiB · `max_decoded_bytes` 1 GiB · `max_ratio` 100 · `ratio_floor_bytes` 16 MiB (oran yalnız bunun üstünde
   denetlenir) · `max_depth` 512 · `max_nodes` 50 000 000 · `max_layers` 8. Yöntemler: `check_input(len) -> Result<()>`
   (`CORE_LIMIT_INPUT`), `output_budget(input_len) -> u64` = `min(max_decoded_bytes, max(ratio_floor_bytes, input_len × max_ratio))`
   (taşmaya karşı `saturating_mul`), `check_output(input_len, output_len) -> Result<()>` (`CORE_LIMIT_DECODED`).

8. **`codec.rs`**
   - `pub struct Confidence(f32)` (0.0–1.0'a kırpılır; `PartialOrd`) · sabitler `NONE` 0.0, `LOW` 0.25, `MEDIUM` 0.5, `HIGH` 0.9,
     `CERTAIN` 1.0 · `value()`.
   - `pub struct SniffCtx<'a> { pub file_name: Option<&'a str>, pub depth: usize }`
   - `pub struct DecodeCtx<'a>`: `limits: &'a Limits`, `depth: usize`, `nodes: u64`, `hints: Params` · `new(&Limits)`,
     `limits()`, `depth()`, `hints() -> &Params` (tarifte bu adıma yazılmış parametreler; ör. parola anahtarı), `with_step(depth, hints)`,
     `charge_nodes(n) -> Result<()>` (`CORE_LIMIT_NODES`), `check_depth(d) -> Result<()>` (`CORE_LIMIT_DEPTH`),
     `output_budget(input_len)`, `check_output(input_len, output_len)` (Limits'e yönlendirir).
   - `pub struct Decoded { pub doc: SaveDoc, pub params: Params }`
   - `pub trait Layer` ve `pub trait Codec` — MIMARI §3.3'teki imzalarla. `Codec::patch` varsayılanı: `decode(original)` (varsayılan
     `Limits`) → `apply_edits` → `encode`.

9. **`registry.rs`** — `pub struct Registry` (`Default`): `BTreeMap<&'static str, Arc<dyn Layer>>` ve aynısı `Codec` için ·
   `add_layer(Arc<dyn Layer>)`, `add_codec(Arc<dyn Codec>)` (aynı kimlik varsa yenisi geçer) · `layer(id)`, `codec(id)`, `layers()`,
   `codecs()` (kimliğe göre sıralı yineleyici) · `is_layer(id)`, `is_codec(id)`.

10. **`pipeline.rs`** (çalışan kod)
    - `pub struct DecodeOutput { pub doc: SaveDoc, pub recipe: Recipe, pub frames: Vec<Vec<u8>> }`: `recipe` = decode'un döndürdüğü
      parametrelerle dolu tarif; `frames[0]` = girdi, `frames[i]` = i. katmanın çıktısı; son çerçeve codec'in girdisi.
    - `pub fn decode(input: &[u8], recipe: &Recipe, reg: &Registry, limits: &Limits) -> Result<DecodeOutput>`: `check_input`,
      `validate`, her katmanda `ctx.with_step(i, step.params)` → `Layer::decode` → `check_output`, sonda `Codec::decode`.
      Her hata bağlam alır: `"while decoding step 2/3 (compression.gzip)"`. Her adım için `tracing::debug_span!` (yalnız indeks, tür ve
      bayt boyu; içerik yok).
    - `pub fn encode(doc: &SaveDoc, recipe: &Recipe, reg: &Registry) -> Result<Vec<u8>>`: codec `encode` → katmanlar tersten `encode`;
      bağlam `"while encoding step …"`.
    - `pub fn encode_from(inner: &[u8], recipe: &Recipe, from_layer: usize, reg: &Registry) -> Result<Vec<u8>>`: verilen baytı
      `from_layer` indeksli katmandan dışarı doğru kodlar (koruma ve CLI kullanır).

11. **Boş gövdeli imzalar** (gövde: `Err(Error::new(codes::CORE_NOT_IMPLEMENTED, "<ad> is not implemented yet"))`; tipler tam):

      pub file_name: Option<String> }` + `Default` · `pub struct Candidate { pub recipe: Recipe, pub confidence: Confidence }` ·

      `pub struct StepReport { pub index: usize, pub kind: String, pub verdict: Verdict, pub reason_key: &'static str, pub detail: String }` ·
      `pub struct GuardReport { pub overall: Verdict, pub steps: Vec<StepReport>, pub editable: bool }` ·
      `pub fn check_round_trip(input: &[u8], recipe: &Recipe, reg: &Registry, limits: &Limits) -> Result<GuardReport>`

## Kabul (testler `#[cfg(test)]` modüllerinde)
1. Tarif TOML'a yazılıp geri okununca eşit; `version = 1` ve `[[layer]]` biçimi; bayt parametresi `base64:` ile geri geliyor;
   `"base64:x"` metni metin olarak geri geliyor; `kind` anahtarlı Params hata veriyor.
2. `SaveDoc`: iç içe belge kurulur, `resolve` çalışır (`~0`/`~1` dahil), `set_value` `lexeme`'i siler, `READ_ONLY` düğüm
   `CORE_READ_ONLY` döner, `tree_eq` `lexeme`/`span` farkını yok sayar, 100 000 derinlikte zincirde yığın taşmaz.
3. `apply_edits`: Set / Insert / Remove / RenameKey çalışır; hatalı ikinci düzenleme ilkini de geri alır (belge aynen kalır);
   `I8` düğüme 300 yazmak hata.
4. Boru hattı: sahte iki katman (ör. XOR anahtar parametreli, ters çevirme) + sahte codec (satırları `Array<Str>` yapan) ile
   `decode` → `encode` bayt-bayt aynı; bilinmeyen tür `CORE_UNKNOWN_STEP`; 9 katman `CORE_LIMIT_LAYERS`; büyük girdi
   `CORE_LIMIT_INPUT`; hata bağlamında `"step 2/3"` geçiyor.
5. `ErrorCode::i18n_key`, `Error::report` biçimi; üç boş imza `CORE_NOT_IMPLEMENTED` döner.
6. `bash .claude/araclar/kontrol.sh rust` çıkış 0 (fmt, clippy `-D warnings`, test) — CEO koşar. Tauri `core_version` derlenmeye devam eder.
