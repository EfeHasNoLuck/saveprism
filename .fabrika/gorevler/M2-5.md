## Yapılacaklar
1. **`format.gvas`** (`gvas/mod.rs`): sniff = ilk 4 bayt `GVAS` → yüksek.
   Decode: `Limits` girdi sınırı → `Save::read_with_types(&mut cursor, types)` (types `Params`'tan; yoksa boş) → `serde_json::to_string`
   → mevcut JSON codec'in decode'u → SaveDoc. Kök düğüme `GVAS:save` ipucu; JSON'daki tip alanlarından (uesave'in yazdığı tip anahtarları)
   en sade şekilde `GVAS:<tip>` ipucu ver; yapamıyorsan verme ve raporda yaz.
   Encode: JSON codec'in encode'u → metin → `serde_json::from_str::<Save>` → `save.write(&mut Vec)`.
2. **Tip ipuçları:** `Params` içinde `types` tablosu (yol → tip adı, ör. `.worldSaveData.CharacterSaveParameterMap.Key` → `Guid`);
   `uesave::Types`'a çevrilir. Decode sırasında kullanılan tablo `Params`'a geri yazılır (encode aynısını kullanır).
3. **Hata:** uesave `ParseError` → `SP-GVAS-001` (bağlamla); serde_json hatası → `SP-GVAS-002`; boyut aşımı → çekirdeğin limit kodu.
   Panik yok (`unwrap`/`expect` yasak).
4. **Kayıt:** `pub fn register(reg: &mut Registry)`.
