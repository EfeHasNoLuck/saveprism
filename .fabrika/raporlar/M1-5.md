## Scoring rule
State score starts at 1.0. Layer success: new state with score = parent score x layer sniff. Codec success: candidate confidence = state score x codec sniff. Search order: higher score first, tie fewer steps. Candidates sorted by confidence, tie fewer steps. Every sniff above NONE costs one attempt; budget reached with no candidate gives DET_BUDGET, otherwise DET_NO_MATCH. Any trial error (including CORE_LIMIT_*) only kills that branch; CORE_LIMIT_INPUT is returned at once. Layer expansion stops at `limits.max_layers`. Also checked per layer: `check_output` and sum of kept bytes <= `max_decoded_bytes`. The codec result is checked with `verify_decoded`.

## Uncertainties
- Not compiled. Possible fmt diffs on the long `tracing::debug!` lines.
- Search does not stop at the first candidate (collects alternatives within the attempt budget), so `attempts` can be above the minimum.
- Wrong candidates are possible when: base64 text is also valid lz-string input (base64 0.5 vs lz 0.4; both are tried, only a codec that parses gives a candidate, so the risk is a text that decodes under both); short alphanumeric text (e.g. a word) may pass as base64 and as lz-string and then parse as JSON in some rare accidental case; a plain JSON with a `.json`-less name gets only 0.7.
- The random-bytes test uses a fixed first byte 0xFF so no sniffer can match by chance.
- Test inputs rely on layers' bare-step defaults for encode (gzip/zlib/base64/lz-string have defaults).
