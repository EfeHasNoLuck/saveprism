## How it works
- sniff: input starts with `GVAS` -> HIGH (0.9), else NONE.
- decode: `Limits::check_input` -> `types` hint table -> `uesave::Save::read_with_types` -> `serde_json::to_string`
  -> `check_output` -> `JsonCodec.decode` (same ctx, so node/depth limits apply). `types` is stored in the returned
  Params (empty table when no hint); the JSON format profile keys stay in the same Params.
- encode: `JsonCodec.encode` -> `serde_json::from_slice::<Save>` -> `Save::write`.
- uesave contains `unwrap`/`assert!`/`unimplemented!` on input paths (seen in lib.rs), so both uesave calls are wrapped
  in `catch_unwind`; a panic becomes SP-GVAS-001 / SP-GVAS-003. (Allocation failure/abort cannot be caught.)
