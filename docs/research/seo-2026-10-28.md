# Search wording for the app and the GitHub page (2026-10-28)

Short research (agy Gemini flash, web search; the volumes are its estimates, not measured) for the one-line
GitHub "About" description.

## What players search
Roughly most to least: "`<game>` save editor" / "save editor", "save editor online", "save file editor",
"rpg maker save editor", "edit save file", "game save editor", "renpy save editor", "pc save editor".
The online competitor describes itself as an online save editor for RPG Maker, Ren'Py, Unity, Unreal Engine and Godot.

## Rules for the line
- "Save editor" first; then the platform ("PC games") and the engines people search for.
- Say what sets us apart: offline, automatic backups.
- 100-160 characters for GitHub (it cuts longer text). No "free" (maintainer, 2026-10-27), no hype words.

## Chosen lines (maintainer, 2026-10-28: About and GitHub stay different)
GitHub description (EN): "Save editor for PC games. Edit Unity, Unreal, RPG Maker, Ren'Py and Godot saves offline, with
automatic backups."
About tagline in the app (unchanged): EN "A save editor that runs on your PC. No account, no upload." / TR "Bilgisayarında
çalışan bir kayıt düzenleyici. Hesap yok, yükleme yok."
