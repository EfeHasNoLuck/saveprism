A free save editor that runs on your PC. No account, no upload.

### What you get
- Open saves from RPG Maker, Unity, Unreal Engine, Ren'Py, Twine, Godot and many more engines and formats.
- Change gold, stats, items, variables and switches in a clear list, or edit the whole save as JSON.
- Safe saving: a backup comes first, every written file is read back and checked, and a save that would not come back
  byte for byte opens read-only.
- Undo and redo, search in every list, compare two saves, restore a backup, and "Where is my save?" for your engine.
- Paste a save code, or copy one back out.
- Make it yours: text size, colors, patterns or your own background photo. English and Turkish.
- AI help: **Ask AI** copies a list for any chatbot, and AI apps (Claude, Cursor, VS Code and others) can open and edit
  saves through the built-in MCP server.
- New versions arrive inside the app.

### Good to know
- The Linux and macOS builds are new and not yet tried on real machines. Found a problem? Please open an issue.
- The installers are not code-signed. Windows: **More info → Run anyway**. macOS: **System Settings → Privacy &
  Security → Open Anyway**.
